## About the Mod

Extra Steps adds production chains for leather and wool, making resource processing a more involved part of Minecraft survival. Animals provide rawhide or unprocessed wool that must be processed before use.

Processing includes scraping, washing, drying, brushing, and compressing. Colors can be mixed during washing to create custom shades for leather armor and placeable wool blocks.

Processing recipes are driven by datapacks, allowing the production chains to be customized and expanded.

This overview is adapted from the [original description on CurseForge](https://www.curseforge.com/minecraft/mc-mods/extra-steps).
